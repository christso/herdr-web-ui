# Agent launch profile proposal

These are labeled design mockups, not evidence of a working feature. They add a Profile field beneath the existing Agent field in New tab and New worktree. New workspace shares the same choice. Default preserves the ordinary agent launch; Compound engineering is an example configured profile.

The selected PC supplies its own available profiles. The profile keeps its base agent identity (Codex, OMP or Pi) for chat parsing. Launcher paths and environment remain on that PC. Existing terminal sessions are not changed by choosing a profile for a new pane.

The HTML is a self-contained interactive design sketch. Desktop captures are 1280x1000; phone captures are 390x1000. Synthetic project names only. Application implementation and verified screenshots will be recorded separately; these images must not be described as passing native tests.
